## Description

`GET /api/links` is fixed to `ORDER BY created_at DESC` with all-time click counts (`internal/links/store.go:676-688`, `internal/handlers/links.go:570-598`). Add search, filters, sorting and a windowed click count, so both an agent's `list_links` tool and the redesigned Links page (#0167) can find links directly.

## Long Description

New query parameters, all optional and backwards-compatible:

| Param | Meaning |
|---|---|
| `q` | case-insensitive match on title, key or destination URL (`ILIKE`, with `%` and `_` escaped) |
| `campaign` | slug, or `none` |
| `source`, `medium` | exact `utm_source` / `utm_medium`, comma-separated |
| `status` | `active` (default when the parameter is present), `inactive`, `expired`, `all` |
| `content_key` | links with this #0140 content key |
| `sort` | `created` (default), `-created`, `clicks`, `clicks_window`, `title` |
| `window` | `7d`, `30d`, `90d`; adds `clicks_window` to each item |

Without any new parameter the response stays exactly as it is today. Each item also gains `content_key` and `label` (from #0140) and `campaign_slug`. Raise `per_page` max to 100.

## Acceptance criteria
