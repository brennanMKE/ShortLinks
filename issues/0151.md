## Description

Write the agent-facing guide and the deploy changes so the MCP server works in production on sstools, ocsf and dustalmanac.

## Long Description

- **`docs/mcp.md`:** what the server offers (tools, prompts, read-only behaviour), how to create a token (link to [docs/using-api-tokens.md](../docs/using-api-tokens.md)), and connection recipes for Claude Code (`claude mcp add --transport http shortlinks https://go.example.com/mcp --header "Authorization: Bearer $SHORTLINKS_TOKEN"`), Claude Desktop and the MCP Inspector. Include five example prompts with the tool each one leads to.
- **Apache:** proxy `/mcp` like `/api`, with response buffering and compression off for streamed responses (`SetEnv no-gzip 1`, `flushpackets=on`), and a timeout long enough for streaming. Update [DEPLOYMENT.md](../DEPLOYMENT.md) and the vhost templates in `deploy/`.
- **Rate limiting:** apply the existing API rate limiter to `/mcp`, and document the limits.
- **Smoke script:** `scripts/mcp-smoke.sh` takes a base URL and token, runs initialize, `tools/list` and `whoami`, and prints the tool count.
- Link `docs/mcp.md` from [README.md](../README.md) and [docs/README.md](../docs/README.md).

## Root cause

The MCP server (#0149, #0150) shipped with tool reference docs but no guide for connecting an agent, no smoke check, and no confirmed proxy setup for `/mcp` behind Apache.

## Fix

**`docs/mcp.md`** (extended) covers:
- full versus read-only tokens;
- connecting Claude Code, with `claude mcp add --transport http shortlinks https://<host>/mcp --header "Authorization: Bearer $SHORTLINKS_TOKEN"` and a project `.mcp.json` using `${SHORTLINKS_TOKEN}`;
- connecting Claude Desktop through `mcp-remote`, and the MCP Inspector;
- 8 example prompts, each mapped to the tool it leads to;
- the limits, described once:
  - 600 requests a minute per token, burst 60;
  - 20 failed attempts a minute per IP;
  - 256 KiB body cap (413);
  - batches rejected (400);
- troubleshooting by status code: 401, 403 `api_token_required`, the cross-origin 403, 405, 413, 429, and the read-only tool error.

**`scripts/mcp-smoke.sh`** runs `initialize`, `tools/list` and `whoami` against a base URL.
- The token comes from `SHORTLINKS_TOKEN`, is checked against the `slk_` format, and reaches curl through `-K -` on stdin, so it never appears in argv.
- No temp files.
- Exit codes: 0 pass, 1 failure, 2 usage.

**Apache.** The existing catch-all `ProxyPass /` already carries `/mcp`, including `Authorization`, `Origin` and the POST body. `ProxyPreserveHost On` is required for the cross-origin check. `deploy/apache/go.sstools.co.conf` gains an optional `/mcp` block above the catch-all (`flushpackets=on`, `timeout=120`, `SetEnv no-gzip` inside `<Location "/mcp">`). It only matters if streaming is ever enabled. `DEPLOYMENT.md` and `deploy/apache/README.md` explain how to apply it to the other instances. Production was not changed.

**Links.** `README.md` and `docs/README.md` link `docs/mcp.md`.

The review fixes went into `6f026a3` on `issue/0151`: the read-only error wording, the token format check, the no-tools guard, and removing the duplicate limits section.

## Verification

```

ok  whoami
PASS: 28 tools   (rc=0)
```

A bad token printed `FAIL: HTTP 401 ... unauthenticated` (rc=1). A malformed token exits 2. I re-checked this myself:

```
error: SHORTLINKS_TOKEN is not shaped like an API token (slk_ followed by letters, digits, - or _)
rc=2
```

The script also passed through a throwaway local Apache using the template's proxy lines.

**Real Claude Code client.** `claude -p --mcp-config <tmp.json> --strict-mcp-config --allowedTools 'mcp__shortlinks__*'`, with the token passed as `${SHORTLINKS_TOKEN}`. `claude mcp add` was not used, and `~/.claude.json` was untouched. The seeded links had 40, 15 and 5 clicks.

```
TOOL_USE mcp__shortlinks__get_top_links {"range":"7d","limit":10}
RESULT {"report":"top-links", ... "highlights":["Top link: \"Alpha\" (/u/alpha) with 40 clicks ...
ANSWER Alpha was your top link over the last 7 days, with 40 clicks.
  1 Alpha 40 | 2 Beta 15 | 3 Gamma 5
```

Against the live local server, a cross-origin `Origin` got 403, `GET /mcp` got 405, and a JSON-RPC batch got 400. The server was stopped, the DB dropped, and the temp config, binary, env file and logs deleted.

**Other checks.**
- `bash -n` and `shellcheck` are clean. The reviewer also ran the script under macOS bash 3.2 against a mock server, covering pass, no token and unreachable.
- `go build ./...` is clean. `go test ./... -count=1` passes in every package except the known `internal/config` `TestLoad_DefaultsApplied` failure (#0116).

## Gotchas

- **Desktop and Inspector recipes are untested.** They follow those clients' documented behaviour; only Claude Code was run for real.
- **Production smoke check.** Running `scripts/mcp-smoke.sh` against one production host with a read-only token after the `/mcp` release is installed is still worth doing.
- **`ProxyPass /mcp` also matches `/mcpfoo`.** That's harmless, because the catch-all sends those to the same backend.
