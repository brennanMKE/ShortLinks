## Long Description

Brennan's feedback, verbatim: *"Currently the home page, when a user is signed in, shows the form to create a new link followed by a list of short links. It could instead just be a chart showing click activity over the past 30 days… if there are any campaigns with clicks during that time it would be convenient to have buttons to switch focus to each one. Then there could be ways to filter by UTM parameters… I cannot see the full title for a link sometimes. That makes it hard to know which content is getting the most attention."*

**Approach:** content is the unit that gets ranked. Every table has one wide identifying column with a two-line cell, at most five columns and a ⋯ menu instead of red buttons in each row. All view state lives in the hash query. The Overview and campaign analytics read from the Go reports (#0139–#0143) rather than adding things up in the browser.

**Change from the design document:** content grouping is computed in Go (#0140) and returned by the reports, not in a `lib/content.ts` module. The campaign Links table (#0157) therefore depends on #0140.
