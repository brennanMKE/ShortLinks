# 0084 — E2E: redirects & click recording (`/u/{key}`)

| | |
|---|---|
| **Status** | open |
| **Module** | web / links / clicks |
| **Platform** | All |
| **First seen** | 2026-07-02 |

## Description

Automate the redirect endpoint `/u/{key}` and the click-recording side effect by
driving Safari through real navigations. Depends on [#0080](0080.md); part of
[#0079](0079.md).

## Scope / scenarios to automate

- **Basic redirect.** Navigating Safari to `http://localhost:8080/u/gh` lands on
  the destination (github.com). Assert the resolved URL (or, to avoid the external
  network, seed a link pointing at a local path and assert that — see Notes).
- **Click recording.** After N redirects through a key, the link's click count /
  clicks chart reflects N (check via LinkDetail or the dashboard stat). Assert the
  increment deterministically.
- **UTM passthrough.** A link with stored UTM params redirects with those query
  params appended/merged onto the destination. Assert the final URL's query.
- **Expired link.** A link whose Expires is in the past does not redirect —
  asserts the expired behavior (e.g. a not-found / expired response) rather than
  sending the user on.
- **Unknown key.** `/u/does-not-exist` returns the 404 / not-found behavior, not a
  redirect.

## Preconditions

- Fresh-seed dev server. Ability to create links with a controlled destination,
  UTM params, and past/future expiry via the API or the create form.

## Acceptance criteria

- [ ] Basic redirect resolves to the destination.
- [ ] Click count increments by the number of redirects performed.
- [ ] UTM params are present on the redirected URL.
- [ ] Expired link does not redirect (expired behavior asserted).
- [ ] Unknown key returns not-found (no redirect).

## Out of scope

- The UTM *builder UI* — #0085 (this issue asserts passthrough at redirect time).
- Analytics chart rendering details — #0085.

## Notes

- To keep tests hermetic and offline, prefer creating links that point at a
  **local** URL (e.g. `http://localhost:8080/health` or a static path) so the
  redirect target is under test control and no external site is hit. Reserve one
  real-domain case (github.com) if you want to prove true external redirects.
- Redirect + click recording resolution logic lives in `handlers` /
  `RedirectHandler` + `ClickRecorder`; assert through the UI-visible count.
