# 0182 — Links have no external id, so a client can't find its link again without storing the key or matching titles

| | |
|---|---|
| **Status** | open |
| **Module** | links / handlers / db |
| **Platform** | All |
| **Phase** | 21 — Invitation links (CoupleDozen) |
| **First seen** | 2026-11-18 |

## Description

CommunityPlatform stores nothing on its side. To deactivate an invitation's link when the invitation is withdrawn, it would have to search by title. Add an optional client-supplied `external_id`, unique per user, and a way to look a link up by it.

## Long Description

Requested by the CommunityPlatform session on 2026-11-18, for CoupleDozen invitation links on the new go.coupledozen.com instance. Their plan is in CommunityPlatform `docs/Plans/2026-11-ShortInviteLinks.md`, with issues GroupsWeb #0274/#0275 and CommunityBackend #0108. Each invitation link carries a secret token that grants entry to a family group, so these links need more protection than marketing links.

**Wanted:**
- **`external_id`:** optional, up to 128 printable ASCII characters. It's set on create or batch create rows, and can be changed with PATCH (null clears it).
- **Uniqueness:** unique per user, enforced with a partial unique index where it's not null. A conflict on create returns 409 `external_id_taken`, with the existing link's key.
- **Lookup:**
  - `GET /api/links?external_id=<id>` returns the matching link or an empty list;
  - plus a shortcut, `GET /api/links/by-external-id/{id}`, which returns 404 when there's no match.
  
  Both go in the MCP tools and OpenAPI later.
- **Dedup interaction:** today, creating a link to a destination you already shortened returns the existing link with `duplicate: true`. When `external_id` is given and the destination is a duplicate with a **different** `external_id`, create a new link instead of merging. Two invitations must never share a link. Document this.
- **Idempotency** (#0147) is unchanged. The two features are independent.

## Acceptance criteria

- Migration with partial unique index, up and down.
- Tests: create with id, lookup both ways, 409 on reuse, PATCH set and clear, per-user scoping, dedup bypass for different ids, batch rows with ids.
- Docs.
- `go test ./...` passes.
