# 0083 — E2E: links list, copy & link detail (edit / delete)

|---|---|

## Description

Automate the "Your links" list, the copy-short-URL action, and the LinkDetail
view's edit and delete flows. Depends on [#0080](0080.md); part of [#0079](0079.md).

## Scope / scenarios to automate

- **List rendering.** Dashboard shows the seed links (columns: short URL,
  destination, title, …). Assert the `/u/gh` → github.com "GitHub" row is present.
- **Copy short URL.** Clicking "Copy" on a row copies the full short URL to the
  clipboard and shows the copied affordance. Assert via clipboard read if Safari
  WebDriver permits, else via the UI state change (note which).
- **Open detail.** Navigating to a link opens `LinkDetail` with its fields, key,
  destination, title, timestamps, and the clicks chart region.
- **Edit.** Change title / destination / expires in LinkDetail → save
  (`PATCH /api/links/{key}`) → assert the change persists (reload / back to list).
- **Delete.** Delete a link (`DELETE /api/links/{key}`) with its confirmation →
  assert the row is gone from the list and the count decreased.
- **Empty state (optional).** On a fresh server with seed links deleted, the list
  shows its empty state.

## Preconditions

- Fresh-seed dev server. Page objects: `DashboardPage` (links table, copy),
  `LinkDetailPage` (fields, save, delete + confirm).

## Acceptance criteria

- [ ] Seed links render; the `gh` row is asserted.
- [ ] Copy action asserted (clipboard or UI affordance — documented).
- [ ] Edit persists and is re-read.
- [ ] Delete removes the row (count −1) after confirmation.

## Out of scope

- The click-analytics chart contents — #0085.
- Redirect resolution — #0084.

## Notes

- Safari WebDriver clipboard access can be restricted; if `navigator.clipboard`
  read isn't available under automation, assert the "Copied" UI state and cover
  the copied *value* by reading the row's href instead.
