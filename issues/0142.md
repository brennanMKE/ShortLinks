# 0142 — There's no quick way to ask what's rising, what's dead, or which campaign is doing best

| | |

## Description

Add three comparative reports that agents and the UI can call directly: `movers` (content and links with the biggest change against the previous period), `idle-links` (active links with no clicks in the window) and `campaign-comparison` (every campaign with activity, side by side).

## Long Description

**`movers`**, extra params `unit=content|link` (default `content`), `limit` (default 5 per list) and `min_clicks` (default 5, applied to the larger of the two periods so tiny numbers don't dominate):

```json
{"unit": "content", "rising": [{"title": "…", "content_key": "…", "clicks": 212, "previous_clicks": 150, "change": 62, "change_pct": 41.3}], "falling": [], "new": [], "gone_quiet": []}
```

`new`: no clicks in the previous period, at least `min_clicks` now. `gone_quiet`: at least `min_clicks` before, zero now. Rank by absolute change, with percentage as the tiebreak.

**`idle-links`**, extra param `min_age_days` (default 7, so links created yesterday aren't flagged): active, non-expired links with zero counted clicks in the window, with `created_at`, `last_clicked_at` (all-time, may be null), campaign and content key. Sorted oldest first.

**`campaign-comparison`**: one row per campaign with at least one counted click in the window, or whose date range overlaps it. Each row has slug, name, status (`live`, `scheduled`, `ended`, `archived`, from the dates), start and end dates, link count, links clicked, clicks, previous clicks, clicks per active day, top content (title + clicks) and top source. Sorted by clicks.

## Acceptance criteria

- All three reports are registered, catalogued and DB-tested, including `min_clicks`, `min_age_days`, expired and inactive links excluded from idle, and campaign status derivation at the date boundaries in `tz`.
- Each report's `highlights` names the single most notable item ("Deep sleep guide is up 41%", "9 links have had no clicks in 30 days").
- Documented in [docs/analytics.md](../docs/analytics.md).
- `go test ./...` passes.
