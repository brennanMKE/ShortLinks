## Description

Automate the "Create a short link" form on the Dashboard end-to-end via Safari
WebDriver. Depends on [#0080](0080.md); part of [#0079](0079.md).

## Scope / scenarios to automate

- **Happy path.** Fill Destination URL only → Create link → a new row appears in
  "Your links" with a generated short key, and the form clears. Assert via the
  UI and that the link count increased from the seed baseline.
- **All fields.** Destination URL + Title + Custom alias + Expires → Create →
  the row reflects the custom alias as the key and the title is shown.
- **Custom alias conflict.** Creating with an alias that already exists (e.g. the
  seed `gh`) surfaces the API error inline; no duplicate row is created.
- **Validation.** Empty/invalid Destination URL is rejected (Create disabled or
  an inline error); assert the form doesn't submit.
- **Expires field.** Setting an Expires value persists it (visible on the link /
  detail); clearing it works. (Layout width of this field was #0053 — not
  re-tested here beyond it being usable.)
- **Filtered destination (if reachable in dev).** A destination matching an active
  URL-filter rule is denied with the reason surfaced. Coordinate with #0090; if
  no seed rules exist in dev, note it and cover the deny-path there.

## Preconditions

- Fresh-seed dev server (mock admin auto-logged-in, 2 seed links).
- Page object: `DashboardPage` (create-form fields, submit, links table, inline
  error region).

## Acceptance criteria

- [ ] Happy-path creation asserted (new row, count +1, form reset).
- [ ] All-fields creation asserted (alias + title reflected).
- [ ] Duplicate-alias error asserted (no duplicate row).
- [ ] Invalid-URL rejection asserted.
- [ ] Expires set/clear asserted.

## Out of scope

- The redirect behavior of the created link — #0084.
- UTM parameters panel — #0085.
- Editing/deleting the created link — #0083.
