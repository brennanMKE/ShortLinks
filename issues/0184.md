# 0184 — Responses are sent uncompressed, and the hashed assets have no long-lived cache headers

| | |
|---|---|
| **Status** | open |
| **Module** | middleware / handlers |
| **Platform** | All |
| **Phase** | 22 — Web performance and stale tabs |
| **First seen** | 2026-11-18 |

## Description

Nothing in ShortLinks compresses responses, and `SPAHandler` (`internal/handlers/static.go`) sets no caching policy for the content-hashed `assets/*` files. Every visit re-downloads the full JS and CSS bundles uncompressed. On opencircuitsf.com the same fix cut a page load from 991 KB to 322 KB.

## Long Description

Requested by the Open Circuit SF website session on 2026-11-18, on Brennan's behalf: port fixes that shipped in opencircuitsf.com v0.17.0. The reference implementation and its plan and review notes are in `/Users/brennan/Developer/OpenCircuitSF/Website` (issues and commits below). Adapt them to ShortLinks rather than copying, because the router, the views and the size of the win all differ. Measure before and after.

**Reference:** Website #0716 (`/Users/brennan/Developer/OpenCircuitSF/Website/issues/0716.md`), commits `2327e4e4` and `40f25e6f`.

**Wanted:**
- **`internal/middleware/compress.go`** wraps the whole mux, with gzip, plus brotli only if the reference uses it.
  - Compress text types only (HTML, JS, CSS, JSON, SVG, plain text, XML). **Never `text/event-stream`**, which covers `/api/events` and MCP streaming responses.
  - Keep `Flush` and `Unwrap` working, so SSE and the MCP SDK (#0149) still stream.
  - Set `Vary: Accept-Encoding`, drop `Content-Length`, and weaken a strong `ETag`.
  - Skip HEAD, 204, 206 and 304 responses, and responses that already carry `Content-Encoding`.
  - **Leave out:** `/u/{key}` redirects (tiny), PNG/ZIP/QR binaries, and `/public/hero` (#0176) if it has landed.
- **`SPAHandler`** gzips each hashed `assets/*` file once at startup and serves the precompressed bytes when the client accepts gzip.
- **Caching:**
  - Hashed assets get `Cache-Control: public, max-age=31536000, immutable`.
  - The HTML shell gets `no-cache`.
  - A missing `/assets/*` returns 404 with `no-cache`, never the HTML shell. The shell would poison a chunk cache; see #0186.
- **Measure:** record transfer sizes for `/` and `/#/campaigns/<slug>` before and after in the resolution notes.

## Acceptance criteria

- Middleware tests cover: text types compressed; event streams untouched and still flushing; binary types untouched; HEAD and 304 untouched; existing `Content-Encoding` passed through; ETag weakened; `Vary` set.
- An MCP streaming or SSE test still passes through the middleware.
- SPA tests cover precompressed assets, cache headers, `no-cache` on the shell, and a 404 for missing assets.
- Checked in the running app via `scripts/dev.sh`. DevTools shows `content-encoding: gzip` and the cache headers.
- `go test ./...` and `cd web && npm test && npm run build` pass.
