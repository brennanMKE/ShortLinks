## Description

Nothing in ShortLinks compresses responses, and `SPAHandler` (`internal/handlers/static.go`) sets no caching policy for the content-hashed `assets/*` files. Every visit re-downloads the full JS and CSS bundles uncompressed. On opencircuitsf.com the same fix cut a page load from 991 KB to 322 KB.

## Root cause

No compression middleware existed and `SPAHandler` set no `Cache-Control`, so every visit re-downloaded the full bundles uncompressed with no caching policy, and a missing `/assets/*` chunk fell through to the extension check with no `no-cache`.

## Fix

Ported from Website #0716 (`2327e4e4`, `40f25e6f`), adapted to ShortLinks. Gzip only; brotli is not used by the reference.

- `internal/middleware/compress.go`: `Compress` wraps the whole handler. Compresses only text types (HTML, JS, CSS, JSON, SVG, plain text, XML). Never `text/event-stream`. Skips HEAD, 204, 206, 304, responses with `Content-Encoding` or `Content-Range`. Sets `Vary: Accept-Encoding`, drops `Content-Length`, weakens strong ETags. `Flush` flushes the gzip stream then the underlying writer; `Unwrap` is kept for `http.ResponseController`. `/u/*` and `/public/hero*` pass through untouched.
- `internal/handlers/static.go`: `SPAHandler` gzips each `assets/*` file once at construction (BestCompression, kept only if smaller), serves it with `Content-Encoding: gzip` when the client accepts gzip and sends no Range. Hashed assets get `public, max-age=31536000, immutable`; the shell gets `no-cache`; a missing `/assets/*` is a 404 with `no-cache`, never the shell.
- `cmd/shortlinks/main.go` (one line in `buildMux`): `middleware.Compress(handler)`. The MCP in-process dispatcher still uses the bare mux.
